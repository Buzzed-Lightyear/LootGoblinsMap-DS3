LOOT GOBLINS MAP
An unofficial, read-only loot map overlay for Dark Souls III (PC, Steam).

It shows a minimap of where you are, with the items you have not picked up yet, and a full
map on a hotkey. It only ever reads the game: it changes nothing in the game, in its files
or in its memory, and it makes no network connections.


HOW TO USE

1. Unzip this folder anywhere you like (not inside the game's folder).
2. Start LootGoblinsMap.exe. Do not run it as administrator.
3. First run: it finds the game through Steam and builds the maps from your own game files.
   This takes about half a minute. If it cannot find the game, it asks for the folder.
4. Press "Start overlay".
5. Start the game yourself, in borderless or windowed mode, and load a character.
   Steam must not be running as administrator.

Windows may warn that the program is from an unknown publisher, because it is not signed.
Choose "More info", then "Run anyway", if you trust where you got it.


KEYS (all can be changed under Settings)

  F7                 full map on and off
  Ctrl+PageUp/Down   layer up and down, while the full map is open
  F8                 settings
  F9                 show or hide the overlay
  F10                mark "something is wrong here" for feedback


WHERE THINGS ARE KEPT

  %LocalAppData%\LootGoblinsMap    maps, settings, themes and logs
  "Open data folder" in the app opens it. "Export feedback" puts a zip with the logs and
  your settings on your desktop; it contains no maps and nothing from the game.

To remove the program, delete this folder and the data folder above.


REQUIREMENTS AND LIMITS

  Windows 10 or 11, 64-bit. Nothing else needs to be installed.
  Dark Souls III from Steam. Tested with game version 1.15.2. The DLC is optional.
  Exclusive fullscreen is not supported: no overlay can be drawn over it.
  The map is a floor plan drawn from where you can walk. It has no walls or buildings.
